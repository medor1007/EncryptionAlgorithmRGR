# Encryption Algorithm RGR

Учебная программа на C++ для демонстрации шифров Хилла и Эль-Гамаля.

## Текущий этап работы

Подготовлен начальный консольный интерфейс. В нём можно выбрать алгоритм и
перейти к операциям шифрования и расшифрования текста и файлов, а также к
генерации ключей. Реализация самих алгоритмов будет добавлена на следующих
этапах.

## Как собрать программу в Linux

```sh
cmake -S . -B build
cmake --build build
./build/encryption_rgr
```

Проект будет состоять из главного приложения и отдельных модулей шифров.
Каждый модуль будет реализован независимо и подключаться через общий интерфейс.

Программа предназначена для учебной демонстрации и не предназначена для
защиты реальных данных.
