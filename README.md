# Encryption Algorithm RGR

Учебная программа на C++ для демонстрации шифров Хилла и Эль-Гамаля.

## Текущий этап работы

Подготовлен консольный интерфейс, общий C-интерфейс модулей и загрузчик
динамических библиотек для Linux и Windows. Реализован байтовый вариант шифра
Хилла. Модуль Эль-Гамаля будет добавлен следующим этапом.

Шифр Хилла обрабатывает байты входного файла по модулю 256, поэтому сохраняет
русские и английские символы, знаки и произвольные бинарные данные. Это учебное
обобщение буквенного варианта шифра.

## Работа с файлами

Для шифрования выбери в меню шифр Хилла, затем «Зашифровать файл». По умолчанию
программа читает `input.txt` и сохраняет шифротекст в `encrypted.txt` в виде
шестнадцатеричных данных. Для расшифрования по умолчанию используются
`encrypted.txt` и `decrypted.txt`. Имена и пути можно заменить при запросе.

## Как собрать программу в Linux

```sh
cmake -S . -B build
cmake --build build
./build/encryption_rgr
```

Проект будет состоять из главного приложения и отдельных модулей шифров.
Каждый модуль будет реализован независимо и подключаться через общий интерфейс.

Программа предназначена для учебной демонстрации и не предназначена для
защиты реальных данных.
