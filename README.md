# Encryption Algorithm RGR

Учебная программа на C++ для демонстрации шифров Хилла и Эль-Гамаля.

## Текущий этап

Собран начальный консольный интерфейс: выбор алгоритма и переход к операциям
шифрования текста, шифрования файлов и генерации ключей. Криптографические
модули будут добавлены следующими этапами.

## Сборка в Linux

```sh
cmake -S . -B build
cmake --build build
./build/encryption_rgr
```

Проект разделяется на главное приложение и отдельные модули алгоритмов.
Каждый алгоритм будет реализован независимо, с общим интерфейсом для загрузки
и вызова из приложения.

Программа предназначена для учебной демонстрации и не заявляется как средство
защиты реальных данных.
