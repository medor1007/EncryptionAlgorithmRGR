# Программа шифрования и расшифрования

Учебная программа на C++17 с модульной загрузкой двух алгоритмов: Хилла и Эль-Гамаля. Шифровые модули собираются как отдельные динамические библиотеки. Файлы и стандартные потоки обрабатываются как двоичные данные.

## Сборка в Linux

```sh
cmake -S . -B build
cmake --build build
```

Для сборки требуется CMake 3.16 или новее, компилятор C++17 и OpenSSL Crypto. При сборке включаются максимальные предупреждения компилятора, а предупреждения считаются ошибками.

## Справка

Запуск без аргументов или с `--help` выводит справку:

```sh
./build/encryption_rgr --help
```

Алгоритмы: `hill`, `elgamal`. Режимы: `encrypt`, `decrypt`, `generate-key`. Каждый аргумент имеет короткий и длинный вариант.

| Аргументы | Назначение |
| --- | --- |
| `-h`, `--help` | Показать справку |
| `-a`, `--algorithm` | Выбрать алгоритм |
| `-m`, `--mode` | Выбрать режим |
| `-k`, `--key` | Прочитать ключ или пару ключей из файла; `-` означает стандартный ввод |
| `-i`, `--input` | Прочитать данные из файла; `-` означает стандартный ввод |
| `-o`, `--output` | Записать результат в файл; `-` означает стандартный вывод |
| `-g`, `--generate-key` | Создать пару ключей перед шифрованием |
| `-s`, `--save-key` | Сохранить бинарную пару ключей |
| `-w`, `--write-key` | Вывести бинарную пару ключей в стандартный поток |
| `-u`, `--menu` | Открыть дополнительное интерактивное меню |

## Примеры

Создать пару ключей:

```sh
./build/encryption_rgr --algorithm hill --mode generate-key --save-key hill.keys
```

Зашифровать файл:

```sh
./build/encryption_rgr --algorithm elgamal --mode encrypt --key elgamal.keys --input report.pdf --output report.pdf.enc
```

Создать ключи и зашифровать данные из стандартного ввода:

```sh
cat report.pdf | ./build/encryption_rgr -a elgamal -m encrypt -g -s elgamal.keys > report.pdf.enc
```

Расшифровать файл:

```sh
./build/encryption_rgr -a elgamal -m decrypt -k elgamal.keys -i report.pdf.enc -o report.pdf
```

Каждый режим криптографической обработки запрашивает пароль через терминал. При первом запуске создаётся запись для учебного пароля `qwerty123`; в `config/access.dat` хранится соль и производный хеш. Для демонстрации интерактивного меню используй `./build/encryption_rgr --menu`.

## Автоматические проверки

```sh
ctest --test-dir build --output-on-failure
./build/crypto_tests ./build/modules/libcipher_hill.so ./build/modules/libcipher_elgamal.so
```

Утилита `crypto_tests` проверяет текстовые данные UTF-8, произвольные двоичные данные, пустой ввод, ошибочные ключи и повреждённые контейнеры. Для каждого шифра выполняются три обратных преобразования.

Программа предназначена для учебной демонстрации и не предназначена для защиты реальных данных.
