# Encryption Algorithm RGR

Учебная программа на C++ для демонстрации шифров Хилла и Эль-Гамаля.

## Текущий этап работы

Подготовлен консольный интерфейс, общий C-интерфейс модулей и загрузчик
динамических библиотек для Linux и Windows. Реализованы байтовый вариант шифра
Хилла и модуль Эль-Гамаля. Для сборки модуля Эль-Гамаля требуется OpenSSL.

Шифр Хилла обрабатывает байты входного файла по модулю 256, поэтому сохраняет
русские и английские символы, знаки и произвольные бинарные данные. Это учебное
обобщение буквенного варианта шифра.

## Работа с файлами

Файлы `input.txt`, `encrypted.txt` и `decrypted.txt` находятся в корне проекта
и используются как значения путей по умолчанию. При запросе пути можно оставить
это значение или указать другой файл. При шифровании программа читает исходные
данные и перезаписывает файл результата шестнадцатеричными данными. При
расшифровании программа читает файл с шифротекстом и перезаписывает файл
результата. Если папки для выходного файла ещё нет, программа создаст их.
При первом входе в шифр программа сама создаёт ключи.
Для шифра Хилла ключи сохраняются в `keys/hill_encryption.key` и
`keys/hill_decryption.key`, для Эль-Гамаля — в `keys/elgamal_encryption.key` и
`keys/elgamal_decryption.key`.
Пункт «Заменить ключи» создаёт новую пару вместо старой, поэтому ранее созданные
шифротексты могут стать недоступны для расшифрования.

## Как собрать программу в Linux

```sh
cmake -S . -B build
cmake --build build
./build/encryption_rgr
```

Сборка создаёт главное приложение и отдельные динамические библиотеки шифров
в каталоге `build/modules`.

Программа предназначена для учебной демонстрации и не предназначена для
защиты реальных данных.
